# BATCH112–115 — Asynchronous pipeline dynamic-library preloads

T112 asynchronously creates a render pipeline whose fragment shader calls
a preloaded dynamic-library function. T113 takes the render options and
reflection callback overload, T114 asynchronously creates the compute
pipeline with a preloaded dynamic library, and T115 exercises vertex-stage
preloading. Each native execution produces linked compute `float 3` and a
red center pixel; callback results are retained by the application during
capture, not called during replay.

The async bridge keeps the application's descriptor snapshot and passes a
separate native descriptor with dynamic-library proxies unwrapped. Capture
serializes the v7/v8 compute/render preload arrays and records their parent
resources. Raw/unwrapped references or oversized arrays are marked
unsupported and rejected by the shared replay descriptor validation.
The already-supported T51 async fixture remains in the sentinel suite.
