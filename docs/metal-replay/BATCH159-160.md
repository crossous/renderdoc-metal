# BATCH159–160：Intersection Function Table 的 buffer 参数

交点函数使用与TLAS查询相符的`instancing`签名，从表中读取Shared uint：值0拒绝三角形，
值1接受。原生Metal Validation下T159=1、T159零值对照=0、T160=1；注入捕获后

设备、身份副本、长度和边界，资源作为表的父依赖进入capture。当前测试为fragment
阶段slot0/range(0,1)，不是所有函数签名和参数组合的完整覆盖。
