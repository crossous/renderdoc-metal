# BATCH124–125 — Compute visible function table

An independent Objective-C Metal Validation probe built a compute pipeline
with a linked visible function, obtained its handle/table, bound the table at
compute buffer slot 1 and returned `7` from the GPU. T124 carries the same
resource chain into capture/replay: a visible function writes all 516 bytes of
the existing private-buffer fixture, which Replay API checks across fill,
dispatch and seek events. The render pass consumes those bytes, confirming the
table-driven dispatch executed. T125 adds `setVisibleFunctionTables:withBufferRange:`
and table `setFunctions:withRange:` using the same GPU path.

The compute descriptor now admits a direct linked visible function as well as
existing intersection functions; raw native function references are preserved
for the capture-time Metal call but remain non-portable and reject on replay.
Linked functions become explicit compute-pipeline resource ancestors. Replay
validates the pipeline/handle/table graph, count, slot and range before native
calls. T124 has 16 malformed capture variants rejected without crashing.
T125 adds 5 malformed range variants. Full T125 regression passed 125 captures,
2682 malformed cases and 1250 lifecycle opens; resident growth 6,602,752 bytes,
log `/tmp/metal-batch125-full.log`. Capture SHA prefixes: T124 `ccbff8491538`,
T125 `b07cf63d6c69`.
