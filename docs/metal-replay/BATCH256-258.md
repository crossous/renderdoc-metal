# BATCH256–258：Bounding-box AS refit

新增末尾 `buildRefittableBoundingBox` / `refitBoundingBox` chunk；捕获和回放均保存
box buffer、offset、stride、数量、交点函数表槽、opaque、禁止重复调用、scratch
及其偏移。AS 元数据在复制/压缩复制后继续传递，refit 前校验资源身份、参数一致性、
容量及跨命令缓冲区顺序。允许 refittable box 作为实例 AS 的子结构。

T256 为基本原位 refit；T257 组合 boxOffset48、scratchOffset256、tableOffset1
及禁止重复交点调用；T258 使用独立目标 AS。三份均通过原生 Metal Validation、
捕获、逐事件 API readback 和 CLI replay：build 后射线 `1/1/0`，refit 后
`0/1/0`。每份 40 个畸形 chunk 被安全拒绝；T218、T234 与 T256–258
五份 API/CLI 哨兵通过；三份×10 生命周期打开通过，驻留内存增长 245760 bytes。
本批未运行累积压力回归或 GUI。

捕获 SHA-256 前缀：T256 `1c0ce0b6ad6f`、T257 `c1061c97ba04`、
T258 `2b7628bba8b`。库及 app 内嵌库 `cbfb8ec0daff…`；app 仅编译未启动。

`IOGPUResource::free called for resource still owned by an IOGPUDevice`。
日志不包含足以将其归因于某次 RenderDoc 测试的证据；重启后短测试未再次触发。

三份 capture 的 build/refit 事件、参数、资源身份与事件前后输出。
