# BATCH136–137：Indexed Triangle 与 Bounding Box AS Build

## 范围

在 T135 单三角形 bottom-level AS 的资源/encoder/write/end 链上，追加两个独立 chunk：

- T136：单个静态 Float3 三角形，UInt16/UInt32 index buffer（零偏移），GPU 执行时读取索引；捕获 index 资源依赖和类型，回放前验证资源种类、长度与 AS/scratch 容量。
- T137：单个静态 bounding-box geometry，默认 stride、零偏移，捕获 box buffer/count 依赖；回放前验证长度、数量与 AS/scratch 容量。

两者均不改变旧 T135 chunk 格式或 capture schema；未支持的 descriptor、motion、多 geometry、非默认参数仍显式拒绝。`supportsRaytracing` 仍为 false，不能把 BLAS build 当作完整 shader 光追能力。
T136 只验证索引资源种类、类型与字节范围；若索引内容由 GPU 动态生成，编码时的 CPU 值不能证明执行时索引最大值，动态索引内容正确性仍由 Metal 应用负责，后续真实场景需单独覆盖。

## 终端验证

T136 UInt16 index 与 T137 bounding box 各在 Metal API Validation 下完成原生/注入 GPU build；AS 分配均为 1536 bytes，GPU 写出的 compacted size 均为 1280。捕获 `t136_capture.rdc`、`t137_capture.rdc` 由定向 API/CLI 回放验证：资源 ID/类型、build 与 write action 顺序，以及 write → build → write seek 对输出 buffer 的读回 `1280 → 0 → 1280`。畸形捕获拒绝脚本验证 T135/T136/T137 分别 18/19/18 例，均未崩溃。
