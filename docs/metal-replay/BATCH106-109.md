# BATCH106–109 — Dynamic-library pipeline preloads

T104–105 established linked dynamic MSL libraries. This batch captures and
replays pipeline descriptor preload references to the wrapped dynamic-library
resource: T106 compute, T107 fragment, T108 vertex, and T109 render pipeline
creation with explicit options/reflection. The fragment and vertex shaders in
T107–109 call the dynamic function, so the red output is not merely metadata.
T106–109 each dispatch a compute kernel producing `float 3` and draw red.

The capture schema is v7 for `MTLComputePipelineDescriptor.preloadedLibraries`
and v8 for render vertex/fragment preloaded arrays. Reading older v1–v7
descriptors leaves these arrays empty. Capture converts wrapped references to
native references before Metal pipeline creation; replay validates all
preload IDs, preserves their resource-record dependencies, and restores the
native descriptor arrays. Raw/unwrapped preload dependencies are marked
unsupported, not serialized as false resource IDs. Binary archives, URL
imports, asynchronous dynamic source options, and more than eight preload
dependencies were outside this batch's path. The dynamic async source
subset was subsequently added in [BATCH110–111](BATCH110-111.md).

```sh
bash util/buildscripts/scripts/test_metal_capture_batch106_macos.sh
bash util/buildscripts/scripts/test_metal_capture_batch107_108_macos.sh
bash util/buildscripts/scripts/test_metal_capture_batch109_macos.sh
```

identity, three-loop CLI, API buffer/pixel/seek, malformed preload IDs
