# BATCH218–220：双盒 AS 的 GPU 射线语义与 compute 交点函数表

T218–T220 补齐 compute pipeline 的交点函数表创建、compute encoder 的单表与
range 绑定，并允许 compute pipeline 的 intersection function handle。三个新 chunk
均追加在枚举末尾，以保持旧捕获的 chunk ID 不变。初版误插入旧编号中间被 T137
旧捕获哨兵发现，已改正并重录本组三份捕获。

新的 `Metal_Ray_Box` 在 stride32 双盒中放置 x=20 与 x=0 两盒，padding 为
干扰值 99。T219 另有 x=40/50 前缀，并使用 boxOffset48、scratchOffset256；
T220 走 compute 交点函数表的 range 绑定。三条原生 Metal Validation 与捕获
均得到 x=0/20/40 射线结果 `1/1/0`；API 回放在 dispatch 事件读回同样结果。
这实际验证第二盒和偏移后双盒的 GPU 几何，而不再仅依赖 AS size。
